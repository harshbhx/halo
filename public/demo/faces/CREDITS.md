# Sample faces: these people do not exist

Every face in this folder is an AI-generated image (StyleGAN / thispersondoesnotexist.com style) of a person who does not exist. None is a photo of a real person. They are used only for Halo's demo mode, fake-camera recordings, screenshots and videos.

All files come from Wikimedia Commons, where each is marked **Public domain** (AI output with no human author). Resized to 512 x 512 for the app.

| File | Shown in the app as | Source (Wikimedia Commons) |
|---|---|---|
| `sam.jpg` | "Sam", the friend enrolled live in the fake-camera demo | https://commons.wikimedia.org/wiki/File:Woman_1.jpg |
| `maya.jpg` | "Maya", sample person | https://commons.wikimedia.org/wiki/File:This_Person_Does_Not_Exist_example.jpg |
| `arjun.jpg` | "Arjun", sample person | https://commons.wikimedia.org/wiki/File:Man_2.jpg |
| `walter.jpg` | "Walter", sample person | https://commons.wikimedia.org/wiki/File:John_Wealthington.png |
| `stranger.jpg` | a face that is never added, to show "No match" | https://commons.wikimedia.org/wiki/File:GAN_Mensch_StyleGAN2.png |

The names, notes and relationships in demo mode are invented.
