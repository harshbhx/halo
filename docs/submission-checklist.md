## 4. Judging, for a last look

Stage one is pass or fail: the project fits the theme and was built with the Skill Pack, "as evidenced by the planning documents in the repository". Stage two weighs four criteria equally (Design is first in the tie-break order):

- **Design:** a complete, coherent product experience, not just a technical proof of concept.
- **Potential Impact:** a credible, specific case for a real problem and a real audience, and the demo actually addresses it.
- **Innovation/Idea:** how creative and novel, and how it differs from existing concepts (prior art is named in the README and on the landing page).
- **Presentation:** the video shows it working end to end; the pitch says what problem, for whom, why it matters; easy to follow.
