# Languages

Halo's main flow is available in English, Hindi and Gujarati: the tour, the tab bar, People, Whisper mode (status, notes, captions, the limits line), the first step of adding someone and the handoff. The strings live in [`src/lib/i18n.ts`](../src/lib/i18n.ts); Settings, Reading, Language switches between them and sets the page's `lang`.

**The Hindi and Gujarati text was translated by the AI coding agent and has not been reviewed by a native speaker.** It should be checked before anyone relies on it. The app says so next to the language picker.

What is not translated:

- Other screens (Today, Practice, Settings, Backups, Privacy, Help) and the landing, privacy, terms and safety pages stay in English for now.
- Whisper lines and notes are the user's own words and are never translated by this layer. Enhanced mode can translate a whisper line, if the user turns it on (see `docs/accuracy.md` and the privacy page).
- The earbud test sentence ("This is how a whisper sounds.") is spoken in English.

Fonts: Instrument Sans and Atkinson Hyperlegible Next have no Devanagari or Gujarati letters, so those scripts use the phone's own system fonts. No font is downloaded from elsewhere.

A unit test (`tests/unit/product.test.ts`) fails if Hindi or Gujarati is missing any key, or drops a placeholder such as `{name}`; an end-to-end test switches the language and checks the People screen.
